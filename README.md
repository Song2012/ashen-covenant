# 灰烬契约 · Ashen Covenant

原创像素暗黑放置 RPG 可玩原型。中文界面，Three.js 像素舞台，Vite 构建。参考暗黑式装备养成与流派决策，不使用原作人物、美术或物品名称。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev -- --port 5188
npm run build
npm run preview -- --port 5189
npm test
```

打开 http://127.0.0.1:5188 。生产文件在 `dist/`，使用相对资源路径，可部署到静态网站子目录。浏览器测试使用 `node scripts/browser-check.mjs`，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装 Chromium，`TEST_URL` 指定预览地址；默认使用 Playwright 安装的 Chromium。

## 已实现

- 灰烬骑士、霜棘秘术师、葬骨行者，每职业两个免费切换流派。裂甲重击具有防御转伤机制。
- 四个有等级门槛与元素抗性的猎场，自动清剿、升级与随机战利品。
- 三个装备槽、三种稀有度、元素词缀协同、传奇寻宝加成，比较装备、出售与上架。
- 世界首领模拟：角色和模拟队友共同削减生命，击败获得传奇装备与余烬，自动开始下一轮。
- 自动钓鱼、兑换鱼获、低概率装备掉落。
- 本地市场：购买商人装备、上架、撤回，金币与物品守恒。
- 自动本机存档、最多八小时离线结算、暂停、损坏存档恢复、背包满自动出售新掉落。
- 桌面与手机布局、键盘焦点、低动态偏好。

## 玩法边界

这是本地可玩原型，并非已上线的多人服务。首领队友与商人明确为模拟，挂单不会假装被真人买走。存档存在浏览器 localStorage，无账号、云端保存或真实交易。不要把本机金币、装备与系统时钟用于真实经济验证。余烬目前为首领奖励储备资源，还没有制作/洗练消耗口。

六个流派目前主要以元素协同区分，尚未实现完整技能树、技能链接、符文之语或召唤物独立结算。四个猎场使用同一哥特建筑结构，配色与场景细节按区域变化，难度和产出由区域数据区分。战斗动画是自动演出，结算以进度条与引擎为准。字体使用本机中文字体，美术均为原创本地像素绘制，不依赖外部资源请求。

## 推荐的下一阶段

1. **Build 深度**：每职业一套主动技能、辅助技能和核心被动；传奇加入改变玩法的特效。将伤害、存活、寻宝三种收益放到同一效率模型，避免单纯战力最大化。
2. **装备价值**：词缀池、词缀档位、物品等级、可交易底材、有限制作和余烬消耗，让低稀有度底材也有价值。
3. **权威多人后端**：账号、服务端时钟、每角色活动状态、可审计掉落随机源与幂等奖励账本。世界首领采用共享事件实例和个人贡献奖励，限制离线期间单次贡献，而非依赖客户端减血。
4. **交易经济**：PostgreSQL 事务托管装备、挂单唯一所有权、金币流水、购买幂等、防双花；加入手续费、到期撤回、价格历史。首领稀有掉落设置账号参与约束。纯挂机不能天然阻止多账号扩大产出。
5. **长期留存**：赛季、收藏图鉴、自动筛选与背包规则；避免要求定时上线或频繁手动领取。

代码边界：`src/engine.js` 为可测试状态与结算；`src/main.js` 为界面和用户意图；`src/scene.js` 为像素演出；`src/style.css` 为响应式主题。
