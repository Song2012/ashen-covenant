# 灰烬契约 · Ashen Covenant

**[直接在线游玩](https://song2012.github.io/ashen-covenant/)** · [GitHub 仓库](https://github.com/Song2012/ashen-covenant)

原创像素暗黑放置 RPG 可玩原型。中文界面，Three.js 像素舞台，Vite 构建。参考暗黑式装备养成与流派决策，不使用原作人物、美术或物品名称。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev -- --port 5188
npm run build
npm run preview -- --port 5189
npm test
```

打开 http://127.0.0.1:5188 。生产文件在 `dist/`，使用相对资源路径，可部署到静态网站子目录。浏览器测试使用 `node scripts/browser-check.mjs`，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装 Chromium，`TEST_URL` 指定预览地址；默认使用 Playwright 安装的 Chromium。

## 已实现

- 首发仅野蛮人、法师两个职业；每职业三个自动挂机流派、三个技能分系与九项可修炼技能。初始3技能点，每级增加1点，每技能最高10级，免费重置。
- 四个有等级门槛与元素抗性的猎场，自动清剿、升级与随机战利品。
- 三个装备槽、三种稀有度、元素词缀协同、传奇寻宝加成，比较装备、出售与上架。
- 世界首领模拟：角色和模拟队友共同削减生命，击败获得传奇装备与余烬，自动开始下一轮。
- 自动钓鱼、兑换鱼获、低概率装备掉落。
- 本地市场：购买商人装备、上架、撤回，金币与物品守恒。
- 自动本机存档、最多八小时离线结算、暂停、损坏存档恢复、背包满自动出售新掉落。
- 桌面与手机布局、键盘焦点、低动态偏好。

## 玩法边界

这是本地可玩原型，并非已上线的多人服务。首领队友与商人明确为模拟，挂单不会假装被真人买走。存档存在浏览器 localStorage，无账号、云端保存或真实交易。不要把本机金币、装备与系统时钟用于真实经济验证。余烬目前为首领奖励储备资源，还没有制作/洗练消耗口。

六流派分别具有清怪、攻速叠层、战吼转伤、火焰首领伤害、冰冷穿抗与闪电清场机制；技能加点支持相关技能协同。技能体系为挂机改编，不是完整复刻暗黑2的等级前置、施法帧数、双持武器结算或法力药水系统，尚无符文之语与技能链接。四个猎场使用同一哥特建筑结构，配色与场景细节按区域变化，难度和产出由区域数据区分。v0.4 的三次命中、死亡与拾取由实际引擎事件驱动，怪物生命显示对应本轮的固定遭遇预算；“面板伤害”用于装备/流派比较，清剿效率还包含范围、抗性与休整折算，首领每秒伤害单独结算。字体使用本机中文字体，美术均为原创本地像素绘制，不依赖外部资源请求。

## 推荐的下一阶段

1. **Build 深度**：增加改变技能行为的传奇特效与职业装备限制，扩展现有技能点体系；完善生命、法力、双持与生存机制。
2. **装备价值**：词缀池、词缀档位、物品等级、可交易底材、有限制作和余烬消耗，让低稀有度底材也有价值。
3. **权威多人后端**：账号、服务端时钟、每角色活动状态、可审计掉落随机源与幂等奖励账本。世界首领采用共享事件实例和个人贡献奖励，限制离线期间单次贡献，而非依赖客户端减血。
4. **交易经济**：PostgreSQL 事务托管装备、挂单唯一所有权、金币流水、购买幂等、防双花；加入手续费、到期撤回、价格历史。首领稀有掉落设置账号参与约束。纯挂机不能天然阻止多账号扩大产出。
5. **长期留存**：赛季、收藏图鉴、自动筛选与背包规则；避免要求定时上线或频繁手动领取。

代码边界：`src/engine.js` 为可测试状态与结算；`src/main.js` 为界面和用户意图；`src/scene.js` 为像素演出；`src/style.css` 为响应式主题。

## v0.3 首发职业

| 职业 | 三个技能分系 | 自动流派 |
| --- | --- | --- |
| 野蛮人 | 战斗技能、战斗专家、呐喊 | 旋风、狂乱、战吼 |
| 法师 | 火焰法术、冰冷法术、闪电法术 | 火球、暴风雪、连锁闪电 |

技能点按职业分别保存，切换职业保留等级、装备和财富。三个预设都可直接选择；加点用于强化专长与协同，不需要手动施法。战吼为魔法伤害，与物理流派区分。

旧存档自动迁移：灰烬骑士转野蛮人（原钢铁流派转战吼，其余转旋风）；霜棘秘术师转法师并对应冰冷/闪电；葬骨行者转法师火球。保留等级、经验、金币、余烬、装备、背包、挂单、当前挂机活动和离线收益。

## v0.4 可信远征

- 12 种地区敌人与五种像素轮廓，精英每五轮出现，目前为外观区分、奖励不变。
- 接敌、三次命中、受击、死亡与真实装备拾取；首领和鱼获有对应反馈。
- 四段原创地区故事与随等级开放的怪物档案。
- 静音、音量、减少动态设置自动保存；合成音效随真实事件播放，后台与暂停安静。
- 35 项引擎测试，原有浏览器回归与新战斗/设置/图鉴检查。`npm run balance` 可生成六流派的 1h/8h 数值基线。

当前基线仍存在成长过快、满包会出售高价值掉落的问题；下一阶段优先解决。Steam 商业开发计划见 [ROADMAP.md](ROADMAP.md)，原创资产与竞品研究记录见 [ART-DIRECTION.md](ART-DIRECTION.md)。此更新是开发里程碑，不是 Steam 发售候选。
